# Tagnivra — roadmap

## Prototype committed
- Responsive Indonesian-language interface for mobile
- Select YouTube, TikTok, or Facebook
- Generate starter keywords and hashtags from a topic
- Copy results to clipboard
- Explicit notice that results are not live trend data

## Next implementation steps
1. Add the approved Tagnivra launcher icon to Android assets.
2. Connect a real AI provider through a server-side endpoint; never expose API keys in the client.
3. Add trustworthy trend signals only from official/authorized sources and label their source and timestamp.
4. Add local history and one-tap reuse/copy.
5. Package and test the Android APK.

## Truthfulness rule
Do not fabricate trend scores, search volumes, popularity counts, or promises of virality. Separate AI-generated suggestions from observed trend data.
